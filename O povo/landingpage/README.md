🎥 Landing Page - Barbie (2023)
Este projeto é uma landing page responsiva desenvolvida como parte do teste prático para a vaga de Aprendiz Front-end do Grupo O POVO. A página apresenta detalhes técnicos, elenco e resenhas do filme da Barbie.
🚀 Como rodar o projeto em sua máquina
Como este é um projeto focado em front-end estático (HTML, CSS e JS puro), você não precisa instalar dependências complexas ou bancos de dados.
1. Pré-requisitos
Um navegador web (Google Chrome, Firefox, Edge, etc).
As imagens do projeto devem estar dentro de uma pasta chamada imgs no diretório raiz.
2. Passo a passo
Baixe ou Clone o repositório:
